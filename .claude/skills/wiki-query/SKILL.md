# Wiki Query

開始查詢前，先讀取 `2-wiki/index.md`，依各主題／專案的範圍宣告與頁面摘要判斷與使用者問題語意相關的候選頁面。

## 搜尋範圍

只查 `2-wiki/`；不查 `1-raw/`、`0-capture/`。

## 回答規則

- 已有足以回答問題的內容 → 綜合作答並標註各論點來源，以頁面連結標示。
- 沒有足以回答的內容 → 不宣稱內容不存在；回報已查範圍與使用過的關鍵字，並建議使用者視需要自行以 Obsidian 全文搜尋。
- 不使用與問題語意無關的頁面作為答案來源。

## 查詢報告

不論查到或查不到，都依 `report-format.md` 輸出固定順序：相關主題 → 查詢紀錄 → 答案（或查無結果訊息）

查詢紀錄必須反映實際工具呼叫，包括：
- 實際使用的 Grep 模式與範圍；
- 原始命中檔名；
- 實際 Read 的頁面，區分「採用進答案」與「Read 後未採用」。

相關主題依 `2-wiki/index.md` 的範圍宣告與本次實際採用頁面的歸屬判定，不另外追蹤頁面中的 Wikilink。
