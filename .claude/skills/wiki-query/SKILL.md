# Wiki Query

開始查詢前，先讀取 `2-wiki/index.md`，依各主題／專案的範圍宣告與頁面摘要，判斷與使用者問題語意相關的候選頁面。

## 搜尋範圍

- 預設只查 `2-wiki/`。
- `2-wiki/` 沒有足以回答的內容時，可以提議擴大到 `0-capture/`，使用者同意才查。
- `1-raw/` 不主動查；只有採用進答案的 wiki 頁面連到某份 `1-raw/` 檔案時，才讀那份檔案。

## 回答規則

- 已有足以回答問題的內容 → 綜合作答並標註各論點來源，以頁面連結標示；來自 `0-capture/` 的內容標註「僅存在於 0-capture，尚未整理進 wiki」。
- 沒有足以回答的內容 → 不宣稱內容不存在；回報已查範圍與使用過的關鍵字，並建議使用者視需要自行以 Obsidian 全文搜尋。
- 不使用與問題語意無關的頁面作為答案來源。

## 查過的頁面

不論查到或查不到，答案最後都附一行，列出實際 Read 過的頁面，區分採用與未採用：

查過的頁面：採用 [[頁面A]]、[[頁面B]]；看過但未採用 [[頁面C]]

只列真的 Read 過的頁面，不得漏列看過但沒用上的頁面。
