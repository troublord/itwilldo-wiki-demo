# itwilldo-wiki-demo

這是 iThome 鐵人賽系列文章的示範知識庫，示範怎麼用 AI（這裡用的是 [Claude Code](連結)），從零開始跟著 Andrej Karpathy 的 [LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) 概念，建立一個屬於自己的個人知識庫。

完整過程（怎麼準備、怎麼跟 AI 對話）寫在文章裡：[連結]

## 這不是模板

這個資料夾長這樣，是因為它是照著**我的**回答（工作流、熟悉度、手邊資料）長出來的。你自己做的話，結構應該會不一樣——這正是這系列文章想講的事：知識庫要自己建，才會變成你的一部份，不是套一個現成模板就好。

如果你想看的是「跑起來長怎樣」，歡迎逛逛；如果你想要一個真的好用的知識庫，建議照文章步驟自己走一次。

## 結構

- `raw/` — 原始資料，只讀
- `wiki/` — AI 整理過的內容
- `CLAUDE.md` — 給 AI 看的規則，說明這個知識庫怎麼運作

細節看 [CLAUDE.md](CLAUDE.md)。
