講者「心心」分享他怎麼用 Obsidian + Claude Code 打造個人第二大腦，重點包含：

1. 從 Milanote 換到 Obsidian 的原因：Milanote 存雲端、結構層層嵌套，AI 難以系統性讀取；Obsidian 本質是管理本地 Markdown 檔案的工具，AI 好操作。
2. 資料夾結構設計給 AI 用：根目錄放 CLAUDE.md 作為總入口（介紹使用者是誰、給資料夾地圖），每個資料夾底下放 instructions.md 作為局部說明（結構、命名規則、操作方式），形成兩層導航，AI 只讀當下需要的層級。
3. 自動化輸入管道：Obsidian Web Clipper（存網頁/推文，也可存 YouTube 字幕含時間戳）、Apple Books Highlights 插件（匯入畫線）、iPhone Action Button + Shortcuts（語音記錄碎碎念到 Daily Notes）。
4. 用 Obsidian Canvas 畫思維導圖取代 Milanote，且因為是本地 JSON 檔案，可以讓 Claude 直接操作/生成。
5. 實際使用方式：把整個筆記資料夾丟給 Claude Code，用 yolo 模式（不問權限）；或用 Obsidian 內的 terminal 插件、AI Chat 功能。
6. 省 Token 技巧：漸進式披露（progressive disclosure）——不整庫讀取，靠 CLAUDE.md + instructions.md 按需讀取；每天開新 session，結束時請 AI 把當天工作寫進 Daily Notes，下次只需讀最近幾天的 Daily Notes 就能接續脈絡；用 Obsidian 官方 CLI 操作筆記省 token。
7. 把 Claude Skills 放進 Obsidian 的 Skills 資料夾，讓 Skill 的參考文件可以跟著筆記庫一起持續更新。
8. 結語引用 Andrej Karpathy 的概念：用 LLM 把原始資訊本地結構化整理，累積出完全私有、任何 AI 都能用的個人知識系統，是 AI 時代不可替代的個人資產。
