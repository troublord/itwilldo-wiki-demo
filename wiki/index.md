# 目錄

這裡列出整理過的所有筆記。想找東西先看這一頁，再點進去看詳細內容。

## 主題

### [[學習與記憶]]
範圍：跟「怎麼學東西、怎麼記得住」有關的內容——記憶怎麼運作、學習方法、筆記方式的選擇（手寫 vs 數位比較）、專注力與資訊留存等。不收單純的知識/事實本身（那些屬於各自的主題），只收「學習/記憶這件事本身」的觀察、方法、想法。

- [[學習與記憶]] — 紙本書寫為什麼比螢幕更好記：記憶不只靠視覺，還有觸覺聽覺等線索，加上手寫本身就是一種大腦處理過程
- [[學習與記憶]] — 有研究佐證：Jared Horvath 的研究與 PISA/PIRLS 數據，說明紙本閱讀在理解與記憶上贏過螢幕

### [[AI知識庫工作流]]
範圍：收集別人怎麼設計、操作 AI 輔助的筆記/知識庫系統的方法與技巧（資料夾設計、自動化輸入、省 token 技巧等），作為以後優化咱們自己這個知識庫的參考靈感。不收咱們自己知識庫實際做了什麼改動（那個記在 [[建設歷程]]）。

- [[AI知識庫工作流]] — 心心的 Obsidian + Claude Code 第二大腦教程：兩層 instructions 導航、Daily Notes 接續脈絡、自動化輸入管道等做法

### [[工作方法與判斷]]
範圍：工作與生活中會反覆用到的判斷框架、決策原則、技術排查方法論——收的是可重複套用的「判斷力」本身，不是單一專案的操作紀錄或臨時決定。

- [[工作方法與判斷]] — 技術排查與工作決策的 Pattern 庫：先確認執行鏈路再改設定、最小必要改動、改共用資源前先搜尋影響範圍等
- [[工作方法與判斷]] — 唯一主線法則：每段工作時間只挑一件事推進，選主線的判準與時機
- [[工作方法與判斷]] — Uncle Bob 不讀 AI 程式碼的關卡策略：用測試/mutation testing 取代人工看碼的信心來源，以及判斷力能不能外包的討論

### [[寫作與敘事]]
範圍：說故事、寫作結構、敘事技巧相關的框架與方法本身。不收用這些方法寫出來的特定文章草稿（那些草稿各自歸位，例如鐵人賽草稿在 [[系列進度]]）。

- [[寫作與敘事]] — 靶心人公式：說故事的七步結構，核心是調動讀者情緒
