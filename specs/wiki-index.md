# Object spec：wiki 索引

Object: `2-wiki/index.md`，`2-wiki/` 的頂層索引頁。

適用範圍：定義 index.md 的維護規則、topic／project 條目格式，以及路由頁拆分門檻。不含一般 wiki 頁面本身的規則（見 `wiki-page.md`）。

## 更新時機

新增 topic、project，或既有分類的範圍發生改變時，更新 index.md。

## 條目格式

每個 topic 與 project 都應包含：

- 名稱
- 對應路徑
- 一句範圍宣告
- 必要時附上一句目前內容摘要

範圍宣告應說明：

- 這個分類主要收錄什麼
- 哪些容易混淆的內容不屬於這裡

範圍宣告定義分類本身的邊界，不得依目前已有頁面反推；Ingest 判斷新內容歸屬時，以範圍宣告為主要依據。

### 範例

```text
### 範例主題

路徑：
2-wiki/topics/example-topic/

範圍：收錄與範例主題直接相關、可持續累積修訂的知識；具有明確交付目標或完成條件的工作不放在這裡，應歸入 project。

- [[範例頁面]] — 此主題中的一篇示範知識頁。
```

## 路由頁拆分

單一 topic 或 project 區塊超過 2000 字元，或其中單一 bullet 超過 800 字元，任一觸發即在該目錄建立 `_index.md` 作為獨立路由頁；搬移後頂層只保留分類名稱、範圍宣告，以及指向 `_index.md` 的連結，路由頁負責維護各子頁的「連結＋一句話摘要」。

## 驗證

可機械檢查：

- 每個 topic／project 條目是否包含名稱、路徑、範圍宣告。
- 區塊字元數是否超過門檻卻未拆出 `_index.md`。

需要語意判斷：

- 範圍宣告是否清楚區分「收什麼、不收什麼」。
- 新內容歸屬判斷是否正確依循範圍宣告，而非反推既有頁面。
